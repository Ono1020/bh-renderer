## 8. 検証計画

物理コードは「絵がそれっぽい」では検証できない。フェーズごとに数値の正解と照合する。

| # | テスト | 方法 | 合格基準 |
|---|---|---|---|
| 1 | 平坦時空 | $M=0$ に設定 | 通常の直線レイトレーシングと一致。円盤は普通の平たい円盤に見える |
| 2 | 光の曲がり角 | 大きな $b$ で1本の光線を追跡 | $\delta \approx 4M/b$ と数%以内で一致 |
| 3 | 影 | 平行光源的な遠方カメラで撮影 | 影の半径が $3\sqrt{3}M$ に対応 |
| 4 | 保存量 | フォトン球付近を長時間積分 | $E, L$（Kerr では $Q$ も）のドリフトが許容範囲内 |
| 5 | 赤方偏移 | 静止放射源を各 $r$ に置く | $g = \sqrt{1-2M/r}$ と一致 |
| 6 | ビーミング | 回転する円盤のみを撮影 | 近づく側/遠ざかる側の明るさ比が $g^3$ の予測と一致 |
| 7 | ケプラー極限 | 遠方 $r=100M$ の粒子軌道 | 周期が $2\pi\sqrt{r^3/M}$ と一致 |
| 8 | 先行研究との見比べ | 同条件で撮影 | Luminet (1979) の円盤像、DNEG の公開画像と定性的特徴（影、高次像、ビーミング）が一致 |

## 9. ロードマップ

### Phase 0: 物理プロトタイプ（GPU に触らない）— ほぼ完了（既存リポジトリで代替可能）

2026-10-27 にユーザーの既存リポジトリ https://github.com/Ono1020/BHraytracer （C++、Schwarzschild 測地線の2階形式＋RK4、固定ステップ $\Delta\lambda=0.01$、単色の円盤つき CPU レンダラー）を精査し、§3.5 の検証を外部テストハーネスで実測した。結果:

- 光の曲がり角: b=20 で実測 0.10805 rad、理論値（2次項込み）0.10736 と 0.6% 以内。b=40 では 0.25% 以内
- 影: 捕獲される最大の b = 2.58、理論値 $3\sqrt{3}M = 2.598$ と 1% 以内（単位はリポジトリの $r_s=1$ 系、$M=0.5$）
- フォトン球: r=1.5 の円軌道が 200,000 ステップ後も維持。L のドリフト約 $10^{-14}$
- 縮小版レンダー（240×240）で、影と上下に回り込む円盤の高次像が正しく出ることを目視確認。元の 1000×1000 はこの VM（2コア）では完走に約20分超の見通し（60.9% 時点で停止）

**判定: Phase 0 の本体（積分器の正しさの確認）はこのリポジトリで達成済みとし、新規に作り直さない。** 本リポジトリは今後「GLSL 移植時の正解を出すリファレンス実装」として使う。ただし Phase 1 着手前に次の3点だけを片づける。

1. **既知の精度欠陥を直す**: `Ray::calcdd2` が $f$ と $dt/d\lambda$ を RK4 の中間ステージでもステップ開始時の値のまま使っている。症状として、近接通過（b=5）でヌル条件のドリフトが最大 $2.3\times10^{-4}$ 出る。ステージごとに $f$、$dt/d\lambda = E/f$ をその位置で再計算するよう直すと、同じテストでドリフトが $8.0\times10^{-13}$ まで改善することを実測で確認済み（修正は数行）
2. **検証テストをリポジトリに残す**: 今回の実測は外部ハーネスで行ったため、このテスト一式（曲がり角、影、フォトン球、保存量）をリポジトリ側にテストとして追加し、移植時の回帰テストにする
3. **未実施のままの項目を切り分ける**: §3.5 の静止源の重力赤方偏移テストは、放射モデルが無い現状コードでは対象外（Phase 2 で実施）。ステップ幅の適応化も現状は固定のままで、Phase 1 で扱う

その他の移植時の注意: 円盤の当たり判定が球座標の $r$ と $|z|$ で行われており、円柱半径での判定になっていない。画としては成立しているが、移植先では §4.6 の方式（赤道面の符号変化）で作り直す。

### Phase 1: Vulkan Compute 最小レンダラー（Schwarzschild）
- フルスクリーンの Compute で、星空 + 影 + 薄い円盤（平面交差のみ、色は単色でもよい）
- 完了条件: 影と、円盤の裏側が上下に見える像が出る。$M=0$ テスト（検証1）が通る

### Phase 2: 円盤の物理を入れる
- §4.2 速度場、§4.3 温度と色、§4.4 の $g$ 補正、§4.5 シアリングノイズ
- 完了条件: ビーミングで左右の明るさが非対称になる。検証 5, 6 が通る

### Phase 3: ボリュームとパーティクル
- 円盤の厚みのレイマーチング、測地線で運動するパーティクルとそのスプラッティング
- 完了条件: 静止画で「板」ではなく「ガス」に見える。パーティクルを時間発展させて動画にしたとき軌道が破綻しない

### Phase 4: Blender 連携
- §7 のアドオンと書き出し、主役メッシュのセグメント交差（§6.4）
- 完了条件: Blender のカメラを動かして再レンダーする、という往復が手作業なしでできる

### Phase 4.5: レンズ／フィルム段（Phase 1 の HDR 出力後なら並行着手可）
- §6.7 のレンズシミュレーション: レンズプリセット読み込み、2回反射ゴースト、絞りマスクの FFT によるスターバースト、前玉の汚れ
- §6.8 のフィルム特性: ハレーションとグレインから着手する
- 検証: ブラックホールなしの点光源シーンで、光源を画面内で動かしたときにゴーストが光源と中心を結ぶ軸上を非線形に変形しながら動くこと。実写のレンズテスト映像と見比べる
- 完了条件: 同じ HDR から「クリーン版」と「カメラを通した版」の2種が出力でき、フレアの強さ・F値・レンズプリセットの変更が画に反映される

### Phase 5: Kerr 化
- $a$ を上げていく。影の歪み、フレームドラッギング、ISCO の移動による円盤内縁の接近
- 注意点: $\Delta = 0$（地平面）と回転軸付近で座標特異点が出る。地平面の手前で積分を打ち切る処理と、軸付近の $\sin\theta$ 割り算のガードが要る
- 完了条件: $a=0$ で Phase 2 までの画と一致すること（回帰テスト）、$a>0$ で影が回転方向にずれて歪むこと

### Phase 6（任意の発展）
- 偏光、ジェット、降着流の落下成分、より高度な放射モデル
- 参考実装として GYOTO や ipole の論文を読む段階

## 10. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| Kerr の式の符号ミス | 画は出るが物理が間違っている | $a=0$ 回帰テストと保存量チェックを常時動かす |
| フォトン球付近で積分が終わらない | 一部ピクセルだけ異常に遅い | ステップ上限と、タイル単位の打ち切り |
| ノイズの継ぎ目・引き伸ばし不足 | 円盤が「回るテクスチャ」に見える | 3D 座標サンプリング + シアリング（§4.5） |
| 数値微分が遅い | 本番レンダーが時間切れ | Phase 2 以降に解析微分へ差し替え可能な構造にしておく |
| Vulkan のボイラープレートで消耗 | 本体に到達する前に飽きる | Phase 0 を別言語で終えてから着手する。ホスト側は最小構成にする |
