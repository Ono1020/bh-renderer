# ADR-0002: 最初は Schwarzschild で検証し、後に Kerr 化する

- 状態: 承認済み (2026-10-27)

## 背景

Kerr 計量は検証可能な正解が少なく、座標特異点の扱いも難しい。
Schwarzschild には影の大きさ等の解析的な正解が多数ある。

## 決定

実装は最初から Kerr の形 (ハミルトン形式) で書き、a = 0 で
テストする。Phase 0 は既存の CPU 実装 BHraytracer で検証済み。

## 帰結

- Kerr 化 (Phase 5) は「a を上げる」作業になり、作り直しにならない
- a = 0 の回帰テストを常時維持する
