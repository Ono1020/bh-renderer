# ADR-0001: 描画方式として測地線レイトレーシング + Vulkan Compute を採用する

- 状態: 承認済み (2026-10-27)

## 背景

光が曲がる現象は「光は直進する」前提のラスタライズや通常の
マテリアルシェーダーでは原理的に扱えない。

## 決定

ピクセルごとに光の測地線を後方に積分するレイトレーシングを本体とし、
GPU 実装には Vulkan の Compute Shader を使う。グラフィックス
パイプラインではなく Compute とするのは、BVH・蓄積バッファ・
パーティクル SSBO の扱いやすさのため。

## 帰結

- Blender のマテリアルは解釈しない。物理パラメータだけを受け取る
- パストレーシングは全面採用しない (理由は ADR-0003)
